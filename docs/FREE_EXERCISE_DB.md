# 动作数据来源

数据源为 [Free Exercise DB](https://github.com/yuhonas/free-exercise-db)，采用 [Unlicense](../ios/calorietracker/Resources/FreeExerciseDB/LICENSE.md)。本仓库保留 Fud AI 基线中的数据及其两个本地扩展动作，不包含原始照片或完整数据集网站。

数据文件位于 `ios/calorietracker/Resources/FreeExerciseDB/dist/exercises.json`，Android 构建仍从该路径读取。此目录名为上游布局遗留，不代表本仓库提供 iOS 应用。

中文名称和说明是本衍生版本增加的本地显示映射，原始动作 ID 保持不变。说明含机器翻译及术语修正，尚未逐句经过专业运动指导审校。
